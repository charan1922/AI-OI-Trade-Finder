## What is this project in one line?

> A small website (runs on your own computer) that lets you **download real stock-market data**, **replay it like a live market**, and **review past trades on charts**.

## The 30-second summary

- The app has **3 screens**: **Market Simulator**, **Data Downloader**, **Backtest**.
- It gets data from **Dhan** (an Indian stock broker) over the internet.
- Data is saved on your computer in a small database file (`data/project-r.db`) and some data files (`data/parquet/`).
- It runs at **http://localhost:5001** after you start it.
- It was **carved out of a bigger, more complicated project** so it stays small and easy to understand.
