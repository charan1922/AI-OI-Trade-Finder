# Read a screenshot

- Describe only what is visible. Say what is cut off, blurry or unreadable.
- Every number in it is the screenshot's, from when it was taken: say "in your screenshot", then check the live
  value with a tool before advising.
- If the live read disagrees with the screenshot, say so and trust the live read.
- Never claim it shows a stock, level or position you cannot point to in it.
